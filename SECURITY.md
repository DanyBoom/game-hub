# Безопасность

Не публикуйте ключи, `.env`, дампы памяти, логи игр, SQLite, серверные папки, копии и скриншоты с адресами/личными путями. Для публичного отчёта достаточно версии, игры, шагов и вручную очищенного сообщения. Утёкший секрет сначала отзовите у издателя, затем удалите из истории публикации.

Renderer работает без Node.js, с sandbox, contextIsolation, CSP, запретом навигации и новых окон. Preload принимает фиксированные операции; main проверяет источник IPC и Zod-схемы. Пути серверов не принимаются от UI: их создаёт main, исходники выбираются нативным диалогом.

EXE, JAR и плагины выполняются с правами текущего пользователя. GameHub не является песочницей для недоверенного кода. Не запускайте его от администратора. Импорт EXE требует предупреждения; загрузка BeamMP ограничена официальным репозиторием и проверяет SHA-256 при наличии digest релиза. Ручной импорт не подтверждает подлинность.

Архивы проверяются на выход за папку, ADS, устройства Windows, ссылки/junction, дубликаты и чрезмерную распаковку. Восстановление идёт в новую папку, старая сохраняется. Гонки с другими программами того же пользователя, одновременно меняющими файловую систему, полностью не исключены.

AuthKey защищён DPAPI в базе, но открыт в TOML BeamMP. Пользовательские файлы копий могут содержать другие секреты. Маскировка консоли не гарантирует анонимность произвольного текста. Не загружайте папку данных приложения на GitHub.

Административного HTTP-порта в production нет. Vite при разработке слушает loopback. Игровые серверы могут слушать все интерфейсы: выбор подсказки «этот компьютер» не ограничивает firewall. Приложение не открывает порты автоматически, не выполняет платные операции и не запрашивает права администратора.

Supervisor запускает процесс без shell, передаёт stdin и штатную команду остановки. При disconnect он просит сервер завершиться. Зависший сервер может требовать ручной диагностики; гарантированное аварийное восстановление и attach к старым процессам не реализованы.

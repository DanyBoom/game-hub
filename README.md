# GameHub

Менеджер игровых серверов: приложение для **Windows 11** и **веб-панель на выделенном Windows / Linux сервере**. Русский интерфейс, тёмная тема, серверы и настройки на вашем компьютере. Без облачной панели, аккаунтов GameHub и телеметрии.

> **Проект навайбкожен**: разрабатывается при значительной помощи генеративного ИИ (vibe coding). Версия **0.4.0 — экспериментальная**, код требует человеческой проверки. Храните отдельные копии важных миров.

### Установить на выделенный сервер

Скачайте исходники этого репозитория на сервер. Из корня проекта:

**Ubuntu 24.04 / Debian 12+, x86_64:**

```bash
sudo bash scripts/install-server.sh auto
# или конкретный порт:
sudo bash scripts/install-server.sh 3080
```

**Windows Server 2022/2025 или Windows 11 x64, PowerShell администратора:**

```powershell
.\scripts\install-server.ps1 -Port auto
# или конкретный порт:
.\scripts\install-server.ps1 -Port 3080
```

Установщик подтягивает Node.js с проверкой SHA-256, зависимости панели, собирает интерфейс и настраивает запуск без рабочего стола. Игровые серверы загружаются **по кнопке «Установить» в панели**. Логин/пароль показываются один раз в терминале сервера; порт и отпечаток HTTPS-сертификата тоже выводятся там. Firewall автоматически не меняется.

[Полная инструкция, HTTPS, обновление и восстановление доступа →](docs/DEDICATED.md)

## Что изменилось в 0.2

- **Перетаскивание файлов:** ZIP/JAR можно бросить прямо в окно открытого сервера. Есть определение типа, предпросмотр, проверка структуры, SHA-256 для одинаковых файлов и копия перед изменениями.
- **Minecraft:** Vanilla, Paper, Fabric, Forge и NeoForge; каталог версий, загрузка ядра и подходящей Java из официальных источников, сид, генерация, сложность, режим, RAM, дистанции, PvP, whitelist и другие правила.
- **Контент Minecraft:** миры ZIP с level.dat в корне, datapacks с pack.mcmeta, плагины Paper и моды выбранного загрузчика. У неподходящего JAR проверяются метаданные. Это не полная проверка совместимости зависимостей.
- **Assetto Corsa 2014:** обнаружение и копирование официального Steam Tool, списки машин/трасс из локальной игры, layouts, практика/квалификация/гонка, INI, entry list, погода и импорт машин/трасс ZIP.
- **ACC:** отдельный официальный сервер, JSON UTF-16LE, классы, сессии, погода, рейтинг, пит-правила, смена пилотов, entry list и BoP.
- **EVO:** отдельный официальный сервер, каталоги cars.json и events_*.json, самостоятельные конфигурации сервера/события, поддерживаемый родным сервером формат передачи настроек, погода и сессии.
- **Все параметры:** формы реальных INI/TOML/properties/JSON, включая массивы участников, дополнительные поля и редкие настройки. Секреты скрываются; неизвестные поля сохраняются.
- Скрытый Windows console host отправляет CTRL+C гоночным серверам. Minecraft останавливается через stop, BeamMP через exit. Для ACC консоль читает реальный log/server.log.

## Как пользоваться

1. Выберите игру в библиотеке и создайте экземпляр.
2. Задайте настройки внутри мастера или карточки.
3. Нажмите **«Установить»**. Minecraft скачивает ядро и Java; BeamMP — официальный EXE. Для AC/ACC/EVO GameHub находит Steam Tool и копирует его в отдельную папку. Если инструмента нет, открывается его штатная установка Steam.
4. Для Minecraft самостоятельно прочитайте и примите EULA. Для Steam Tools необходим законный доступ аккаунта; сообщение Steam «Нет лицензий» не обходится.
5. Перетащите доверенные файлы в открытый сервер или во вкладку контента. Для BeamMP Lua/MC datapacks можно явно выбрать тип импорта.
6. Выполните диагностику и запустите сервер. Готовность проверяйте в консоли.

Серверное ПО, платный игровой контент и игры **не распространяются внутри установщика GameHub**. Загрузка/обнаружение запускаются из интерфейса; Steam может требовать свою авторизацию и подтверждение установки. Существующие установки игр не редактируются: серверы работают в отдельных UUID-папках.

## Проверка

Автотесты проверяют конфигурации, ZIP, пути Windows, секреты, SQLite и дочерние процессы. На компьютере разработки реальные **AC, ACC и EVO** открыли TCP-порты и завершились через CTRL+C. Для EVO зафиксировано прослушивание UDP. Проверены настоящий drag-and-drop в Electron, список карт, сид и выбор пяти ядер.

Это не испытания с подключёнными игровыми клиентами. Доступность из интернета, пользовательские моды, driver swaps и длинные гонки требуют игровой проверки. Поддержка установщика ядра не гарантирует существование сборки для каждой версии Minecraft; устаревшие и несовместимые версии отклоняются с ошибкой поставщика.

## Разработка

Windows 11 x64, **Node.js 24 LTS**, npm. ConsoleHost собирается штатным .NET Framework C# compiler Windows; отдельный .NET SDK пользователю не нужен.

```powershell
npm ci
npm run dev
```

```powershell
npm run typecheck
npm test
npm run check:privacy
npm run build
npm run dist
```

NSIS и portable находятся в release/. Установщик не подписан Authenticode. Пользователю не требуется устанавливать Node.js для запуска EXE.

## Приватность и копии

- SQLite, runtime Java и копии находятся в системных данных приложения. Игровые экземпляры по умолчанию — в Documents/GameHub Servers/<UUID>, вне checkout.
- AuthKey и основные игровые пароли хранятся в базе через Windows DPAPI; интерфейсу сохранённые значения не возвращаются. Пустой ввод AuthKey сохраняет прежний ключ.
- Игровым серверам всё равно нужны открытые секреты в своих локальных конфигурациях. **Не публикуйте серверные папки.** У EVO родной протокол может передавать конфигурацию в аргументах процесса; это не защита от другого процесса того же пользователя Windows.
- Из известных конфигураций в копиях секреты очищаются. При восстановлении основные ключи берутся из DPAPI. Неизвестные файлы, миры и моды могут содержать другие личные данные.
- Копируются остановленные серверы. Пользовательские JAR-моды/плагины сохраняются; ядра, EXE/DLL, официальные kspkg, библиотеки и кеши исключены. После восстановления серверное ПО можно установить снова.
- Проверяются SHA-256 копий, ZIP traversal, ADS, устройства Windows, ссылки/junction, дубликаты и лимиты распаковки. Старая папка перед восстановлением сохраняется.
- Нет загрузки логов или аналитики. Известные ключи, IP и типичные личные пути маскируются в консоли эвристически; перед публичной отправкой проверяйте текст вручную.
- Коммиты используют GitHub noreply; исходники, сборка и тесты проверяются в Windows CI. В Git не попадают игры, ключи, SQLite, логи и миры.

## Что ещё не завершено

Bedrock и дополнительные игры остаются следующими этапами. LMU — только официальная информация о Hosted Servers/RaceControl. Нет автоматического firewall, CGNAT-проверки, расписания копий, автоматического отката ядра, гарантированного восстановления процесса после аварии и полного независимого security review. Существующий PID после сбоя не используется для автоматического kill/attach.

Поддержка всех полей конфигурации не означает копию каждой функции и UX оригинальных панелей. Установка модов ACC/EVO не обещается без подтверждения официальной поддержки. Нет Docker-оркестрации и удалённых агентов; выделенная панель управляет процессами на своей машине.

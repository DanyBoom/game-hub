# GameHub

Локальный менеджер игровых серверов для **Windows 11**. Русский интерфейс, тёмная тема, реальные процессы и файлы. Без облачной панели, аккаунтов GameHub и телеметрии.

> **Проект навайбкожен.** GameHub создаётся при значительной помощи генеративного ИИ (vibe coding). Код требует человеческой проверки. Это экспериментальная версия **0.1.0**, а не готовый коммерческий продукт. Не используйте единственную копию важного мира для экспериментов.

## Реализовано

- Electron + React + TypeScript, sandboxed preload, валидируемый IPC, локальная SQLite.
- Мастер создания нескольких отдельных экземпляров сервера.
- **BeamMP**: загрузка EXE из официального репозитория с подтверждением, импорт EXE, редактирование TOML, поле ввода AuthKey, карта, лимиты, импорт ZIP машин/карт с предпросмотром состава, включение/отключение контента.
- **Minecraft Java — Vanilla / Paper**: импорт JAR, выбор установленного `java.exe`, RAM, режим, сложность, создание мира сервером и импорт ZIP мира. JAR-плагины только для Paper. Явное принятие EULA.
- Вывод stdout/stderr, команды stdin; остановка BeamMP через `exit`, Minecraft через `stop`. Приложение ожидает завершения, не убивает зависший сервер автоматически.
- Фактические CPU/RAM, проверка TCP/UDP, адреса LAN и инструкции подключения.
- ZIP-копии остановленных серверов, SHA-256, восстановление с сохранением прежней папки.
- Трей: свернуть с серверами либо штатно остановить перед выходом.
- Сборка NSIS и portable для Windows x64. Пользователю не нужен Node.js.

**Реализация не означает проверку в игре.** Автотесты проверяют конфигурации, архивы, процессы и безопасность путей. Подключение настоящих BeamNG/Minecraft-клиентов в среде разработки не проверялось. Статус «Процесс запущен» не означает готовность сервера или доступность из интернета.

| ----------------------------------- | ----------------------------------------------------------------------- |
| BeamMP                              | Первый адаптер, требуется игровое тестирование                          |

| Fabric / Forge / NeoForge / Bedrock | Не реализовано                                                          |

## Разработка и сборка

Windows 11 x64, **Node.js 24 LTS**, npm.

```powershell
npm ci
npm run dev
```

```powershell
npm run typecheck
npm test
npm run check:privacy
npm run build
npm run start
npm run dist
```

Установщик и portable: `release/`. Authenticode не настроен; Windows может предупреждать о неподписанном приложении. Артефакты не включаются в исходный Git-репозиторий.

### BeamMP

1. Установите VC++ Redistributable по [официальной инструкции](https://docs.beammp.com/server/create-a-server/).
2. Создайте экземпляр, введите свой AuthKey, полученный самостоятельно на Keymaster.
3. Нажмите «Установить BeamMP», подтвердите загрузку или импортируйте официальный EXE.
4. Выполните диагностику, запустите сервер и проверьте консоль.
5. Добавьте ZIP через «Контент»; для карты укажите фактический `/levels/.../info.json`.

### Minecraft

1. Скачайте [Vanilla JAR](https://www.minecraft.net/en-us/download/server) или [Paper](https://papermc.io/downloads/paper).
2. Установите Java нужной версии: требования зависят от ядра. GameHub не предполагает одну Java для всех версий.
3. Создайте экземпляр, выберите ядро, прочитайте [EULA](https://www.minecraft.net/eula) и явно отметьте согласие.
4. Импортируйте JAR, выберите `java.exe`, проверьте диагностику и запустите сервер.
5. ZIP импортируемого мира должен содержать `level.dat` в корне. Перед изменением мира остановите сервер.

## Приватность

- Исходники не содержат личных путей, ключей, игровых данных и адресов пользователя. Коммиты разработки используют техническую идентичность без личной почты.
- SQLite и копии находятся в системной папке данных приложения; серверы по умолчанию — в `Documents/GameHub Servers/<UUID>`, вне checkout.
- AuthKey вводится скрытым полем, хранится в базе через **Windows DPAPI / safeStorage** и не возвращается renderer. Пустое поле при редактировании сохраняет прежний ключ.
- **BeamMP требует открытый AuthKey в своём `ServerConfig.toml`.** Этот локальный файл нельзя публиковать. DPAPI не шифрует конфиг самого сервера.
- Из копий GameHub AuthKey BeamMP удаляется; после восстановления используется ключ DPAPI. Произвольные миры и файлы могут содержать другие секреты/данные игроков: копии приватны и не предназначены для публикации.
- Консоль хранит до 600 строк в памяти; известный ключ, IP и типичные личные пути маскируются. Это эвристика, а не универсальная анонимизация. Игры могут вести свои логи на диске.
- Нет аналитики, отправки crash reports, автообновлений и определения публичного IP. Ручная загрузка BeamMP обращается к GitHub, справка открывает официальный сайт. Серверы обращаются к сервисам своих игр.
- `.gitignore`, `check:privacy` и CI снижают риск случайной публикации, но не заменяют аудит.

## Ограничения

Пока нет автоустановки Java, SteamCMD, полного редактора файлов, drag-and-drop, расписания копий, отката ядра, автоматического firewall, определения CGNAT, автоперезапуска после аварии и английского интерфейса. Контент импортируется через системный диалог. Неизвестные поля конфигурации сохраняются; комментарии TOML при сериализации теряются.

Supervisor при потере приложения запрашивает штатную остановку. Зависший сервер или аварийное выключение ПК не позволяют гарантировать сохранение. Сохранённый PID не используется для kill/attach: найденный старый PID блокирует повторный запуск до ручной проверки и следующего перезапуска GameHub. Windows может переиспользовать PID.

Копии исключают EXE/JAR/DLL, кеши и логи. После восстановления ядро и JAR-плагины импортируются заново. Это копии данных, а не полный снимок установки. Лимиты ZIP: 20 000 элементов, 4 ГБ распакованного объёма, 1 ГБ на файл, коэффициент до 1000. Для больших миров может потребоваться ручная копия.

# Текущий этап

0.2 добавляет отдельные AC, ACC и EVO, установку Minecraft/Java, пять ядер, игровые формы и drag-and-drop. Проверен реальный запуск гоночных серверов с TCP и штатной остановкой. Игровые клиенты не подключались.

Далее: тесты длинных сессий и модов, согласованное копирование работающих миров, Valheim, гарантированное аварийное восстановление, расписание копий, обновления/откат ядра, расширение прав игроков и локализация. Bedrock и AMS2/rFactor2/ETS2 — после основных игр. LMU не выдаётся за локальный dedicated server.

Нельзя называть готовность процесса доказательством доступа из интернета или обещать неподдерживаемый моддинг ACC/EVO. Покрытие оригинальных панелей расширяется по фактической документации и тестам, без заявления о полном соответствии 1:1.

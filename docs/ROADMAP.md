# Текущий этап

0.3 добавляет управление модами, HTTPS-панель Windows/Linux, два установщика и новые адаптеры Terraria, Valheim и Factorio поверх AC/ACC/EVO и Minecraft/BeamMP. Проверен реальный запуск гоночных серверов с TCP и штатной остановкой. Игровые клиенты не подключались.

Далее: тесты длинных сессий и модов, согласованное копирование работающих миров, полевые проверки Valheim и служб, гарантированное аварийное восстановление, расписание копий, обновления/откат ядра, расширение прав игроков и локализация. Bedrock и AMS2/rFactor2/ETS2 — после основных игр. LMU не выдаётся за локальный dedicated server.

Нельзя называть готовность процесса доказательством доступа из интернета или обещать неподдерживаемый моддинг ACC/EVO. Покрытие оригинальных панелей расширяется по фактической документации и тестам, без заявления о полном соответствии 1:1.

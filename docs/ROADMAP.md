# План

0.1 содержит UI, хранение, BeamMP, Minecraft Vanilla/Paper из импортированных JAR, команды штатной остановки, контент, сетевые проверки и копии остановленных серверов. Требуется игровое тестирование.

1. Проверить реальные BeamMP/BeamNG и Minecraft-клиенты, VC++/Java, карты и чистую Windows 11.
2. Разделить сервисы. Assetto Corsa 2014: INI, entry list, cars/tracks, пресеты, остановка. AssettoServer проверяется отдельно.
3. Minecraft: версии и Java, Fabric/Forge/NeoForge, совместимость модов, datapacks, права игроков, обновления/откат.
4. Valheim: Steam Tools, миры, CTRL+C, Crossplay, сохранения, доступ, зависимости модов.
5. EVO и ACC: отдельные официальные конфигурации, режимы и сессии без предположений о моддинге AC.
6. Только затем AMS2, rFactor 2 и ETS2. LMU — информация о хостинге до подтверждения локального dedicated server.
7. Production: подписанный installer, локализация, аварийное восстановление, расписание копий, quota, обновления, независимый security review.

Не выдавать карточки за адаптеры, статус процесса за доступность из интернета или тестовый subprocess за проверку игры.

# GameHub Server

Одна веб-панель для игровых процессов на собственном выделенном сервере. Это отдельный способ запуска GameHub: Electron и рабочий стол серверу не нужны. Приложение Windows продолжает работать локально.

## ОС и игры

| Игра                      | Windows x64                         | Linux x86_64                     | Установка                                                 |
| ------------------------- | ----------------------------------- | -------------------------------- | --------------------------------------------------------- |
| BeamMP                    | Да                                  | Ubuntu/Debian, сборка поставщика | Автоматическая загрузка официального GitHub release       |
| Minecraft Java, пять ядер | Да                                  | Да                               | Ядро и Java автоматически; EULA принимается пользователем |
| Terraria vanilla          | Да                                  | Да                               | Официальный сервер terraria.org                           |
| Valheim                   | Да                                  | Да                               | SteamCMD anonymous; доступность пакета определяет Steam   |
| Factorio                  | Нет автоустановки                   | Да                               | Официальный headless factorio.com                         |
| AC / ACC / EVO            | При наличии официального Steam Tool | Нет                              | Копирование законно установленного инструмента Steam      |

Linux-установщик рассчитан на Ubuntu 24.04 / Debian 12 и новее на x86_64, Windows — на Server 2022/2025 и Windows 11 x64. Это не обещание поддержки всех дистрибутивов, старых Windows или ARM. Клиентские игры и их лицензии не входят в панель. Linux-панель не пытается запускать Windows-only гонки через Wine.

## Установка Linux

Можно скачать отдельный install-server.sh из GitHub Releases: он загрузит соответствующий архив GameHub Server и сверит SHA-256. Либо сначала скачайте и просмотрите исходники:

```bash
git clone https://github.com/DanyBoom/game-hub.git
cd game-hub
sudo bash scripts/install-server.sh auto
```

Вместо `auto` можно указать, например, `3080`. Автоматический порт выбирается ОС из свободных; установщик сохраняет выбранный номер для следующих запусков службы.

Скрипт устанавливает системные библиотеки для игровых серверов, Node.js 24 с проверкой официального SHA-256, собирает панель и создаёт службу `gamehub`. Приложение работает от отдельного пользователя `gamehub`, не от root. Код находится в `/opt/gamehub`, данные — в `/var/lib/gamehub`, runtime — в `/opt/gamehub-node`. Служба может писать только в свою папку данных и временную папку.

```bash
sudo systemctl status gamehub
sudo journalctl -u gamehub -n 100
sudo systemctl stop gamehub
sudo systemctl start gamehub
```

Остановка запрашивает сохранение игровых серверов. На завершение отводится 120 секунд системой службы; для очень больших миров сначала остановите экземпляры в панели и дождитесь их выхода.

## Установка Windows

Отдельный install-server.ps1 из GitHub Releases сам загружает архив GameHub Server с проверкой SHA-256. Либо запустите его из скачанного репозитория. В PowerShell администратора:

```powershell
.\scripts\install-server.ps1 -Port auto
```

Либо `-Port 3080`. По умолчанию файлы находятся в `%ProgramData%\GameHubServer`. Можно задать другую папку через `-InstallRoot`. Скрипт скачивает переносимый Node.js 24 с проверкой SHA-256, собирает панель и создаёт задачу `GameHubServer` при запуске системы. Используется встроенная учётная запись Local Service, без пароля пользователя и без автоматического входа в Windows. Доступ к папке данных ограничивается ACL.

Windows должен разрешать выполнение доверенного локального PowerShell-скрипта согласно своей политике. Установщик не отключает защиту Windows и не меняет execution policy.

```powershell
Get-ScheduledTask -TaskName GameHubServer
Start-ScheduledTask -TaskName GameHubServer
```

Для сохранения миров перед обслуживанием остановите игровые экземпляры в панели. Либо из папки установки используйте свой `node.exe` и команду:

```powershell
node app\dist-server\server.cjs --data data --shutdown
```

Команда создаёт локальный запрос, панель запрашивает штатную остановку и завершает работу. Дождитесь состояния `Ready` задачи. `Stop-ScheduledTask` может прервать дочерние процессы, поэтому не используйте его для обычного сохранения миров.

Официальные Steam Tools для AC/ACC/EVO должны быть установлены законным способом на этой Windows-машине и доступны служебной учётной записи. GameHub не собирает пароль Steam и не обходит сообщение «Нет лицензий». BeamMP, Terraria и Minecraft не требуют ручного выбора установочного файла.

## Адрес, пароль и HTTPS

При первой установке терминал выводит:

- логин `admin` и длинный случайный пароль;
- выбранный TCP-порт панели;
- SHA-256 отпечаток HTTPS-сертификата.

Откройте `https://АДРЕС-СЕРВЕРА:ПОРТ`. Разрешите этот TCP-порт в firewall хостера/ОС; установщик не меняет firewall. Игровые порты отдельные: они показываются в настройках каждого экземпляра. Для BeamMP нужны TCP+UDP, для Valheim обычно два соседних UDP-порта, Factorio использует UDP. Проверка свободного порта не доказывает доступность из интернета.

По умолчанию сертификат самоподписанный: его доверие и имя в браузере требуют ручной настройки. Сверьте отпечаток с терминалом сервера; для постоянного публичного доступа используйте сертификат своего домена. Можно передать Node-процессу `--tls-cert /path/fullchain.pem --tls-key /path/privkey.pem` и настроить эти параметры в службе/задаче. Служебной учётной записи нужен доступ на чтение ключа. Панель не пересылает пароль по HTTP и не принимает произвольные proxy-заголовки.

Сессии истекают через 8 часов и сбрасываются при перезапуске. Есть ограничение попыток входа, HttpOnly/Secure/SameSite cookie, проверка Origin и CSRF-токен. Это панель одного владельца: отдельных ролей, нескольких пользователей, 2FA и внешнего security audit пока нет.

## Восстановление доступа

Остановите панель. Запустите её Node-команду с тем же `--data` и `--reset-password`. Новый пароль появится в терминале. Затем запустите службу снова. Linux-пример:

```bash
sudo systemctl stop gamehub
sudo -u gamehub /opt/gamehub-node/bin/node /opt/gamehub/dist-server/server.cjs --data /var/lib/gamehub --reset-password
sudo systemctl start gamehub
```

Не удаляйте `encryption.key`: без него сохранённые игровые ключи не расшифровать. Пароль панели хранится в виде salted scrypt-хеша; игровые ключи — AES-256-GCM с отдельным локальным ключом. Другой процесс того же системного пользователя имеет сопоставимые права. Резервируйте папку данных целиком и храните её приватно; игровые ZIP-копии не заменяют копию базы и ключа.

## Обновление

Сначала остановите игры и панель, сохраните приватную копию данных. Скачайте новую версию исходников. Linux: повторно запустите установщик из нового checkout; папка данных сохраняется. Windows: скопируйте новые исходники в `app`, выполните `npm ci --ignore-scripts` и `npm run build:server` переносимым Node из `node`, затем снова запустите задачу. Повторная регистрация существующей Windows-задачи специально отклоняется. Не выполняйте обновление поверх работающих процессов.

Для изменения порта задайте `--port ЧИСЛО` в службе/задаче после остановки. Для повторного автоматического выбора используйте `--port auto` и прочитайте итог в `data/panel.json` или Linux `/var/lib/gamehub/panel.json`.

## Моды

Во вкладке контента доступны поиск, фильтр состояния, массовое переключение, SHA-256 файла, настройки и карантин. Редактор ищет совпадающие текстовые конфиги Minecraft в `config`/`plugins` и конфиги внутри Lua-плагинов BeamMP. Иногда их нужно сначала сгенерировать запуском игры. Не все моды хранят настройки в узнаваемом виде; это не универсальный редактор любого бинарного формата.

Для Factorio переключение меняет `mods/mod-list.json`, для Minecraft — расширение JAR, для папки BeamMP — расположение вне активного каталога. Изменения выполняются после остановки, с копией. Карантин можно вернуть через резервную копию или вручную на сервере. Совместимость зависимостей модов не проверяется полностью. Terraria здесь vanilla, без tModLoader; автоустановка BepInEx для Valheim пока не добавлена.

Панель выполняет игровые процессы и доверенные моды с правами своего системного пользователя. Не загружайте чужой исполняемый контент в личную административную панель. Конфиги, логи, базы, сертификаты, пароли и миры не нужно отправлять в публичный репозиторий.

Полевое ограничение 0.3: SteamCMD в проверке Valheim на машине разработки вернул Missing configuration для app 896660. Поэтому успешный запуск Valheim пока не подтверждён. Автоустановка и копирование уже установленного официального Tool реализованы; Terraria и Factorio проверены отдельными настоящими процессами.
